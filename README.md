# WordVault - Vocabulary Builder Flashcards

Expand your vocabulary in any language with flashcards, definitions, examples, and spaced repetition.

## Features
- Vocabulary flashcard decks
- Pronunciation audio simulation
- Definition & example sentences
- Progress mastery stats

## Tech Stack
- **Vite** & **React 18** with TypeScript
- **Tailwind CSS** for responsive mobile-first styling
- **Workbox / Vite PWA Plugin** for offline caching & service worker lifecycle

## Development
```bash
npm install
npm run dev
```
